# 《深入理解计算机系统》第三章笔记

## 程序的机器级表示

### 3.1 历史观点

Intel 处理器系列俗称 **x86**，经历了长期的进化：

1. **8086** (1978)：16 位，1MB 寻址空间
2. **80386** (1985)：32 位，平坦寻址模型
3. **x86-64** (2003)：64 位，向后兼容

> [!note] 关键概念
> 机器代码只是字节序列，反汇编器可以将字节码还原为类似汇编代码的文本格式。

### 3.2 数据格式

| C 类型     | Intel 助记     | 字节 |
| -------- | ------------ | -- |
| `char`   | `b` (byte)   | 1  |
| `short`  | `w` (word)   | 2  |
| `int`    | `l` (long)   | 4  |
| `long`   | `q` (quad)   | 8  |
| `float`  | `s` (single) | 4  |
| `double` | `l` (long)   | 8  |

### 3.3 操作数指示符

```c
// 简单的 C 代码
long exchange(long *xp, long y) {
    long x = *xp;
    *xp = y;
    return x;
}
```

编译为汇编后：

```asm
exchange:
    movq    (%rdi), %rax    ; 读取 *xp
    movq    %rsi, (%rdi)    ; 写入 y
    ret                     ; 返回原值
```

> [!tip] 记忆技巧
> `movq` 中的 **q** 表示 quad word（8 字节）。还有一个重要的细节：**立即数**不能作为目标操作数。
