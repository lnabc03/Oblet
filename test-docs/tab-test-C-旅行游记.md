# 京都游记 — 岚山竹林

## 出发前

从京都站搭乘 **JR 嵯峨野线**，约 15 分钟到达嵯峨岚山站。建议早上 **7 点前**到达，避开旅行团人流高峰。

> [!warning] 注意
> 竹林小径没有路灯，天黑后（约 17:30 冬季）非常暗，务必在天黑前游览完毕。

## 竹林漫步

### 视觉感受

- 竹竿直插云霄，最高可达 **20 米**
- 风吹过时竹竿相互碰撞发出独特的"咔嗒"声
- 晨光穿透竹叶间隙，形成斑驳的光影效果

### 拍摄建议

1. 使用 **广角镜头**（16-24mm），仰拍突出高度感
2. 逆光拍摄竹叶透光效果最佳
3. **避开正午**——顶光在竹林里会产生刺眼的高反差

> 竹林小径全长仅约 400 米，慢慢走 15 分钟就能走完。但建议留 **至少 1 小时**——每一步的光影都在变化，值得反复驻足。

| 野宫神社   | 300m   | 良缘祈愿、苔藓庭园     |
| 龟山公园   | 500m   | 山顶展望台、红叶名所   |

### 午餐推荐

在附近的 **岚山よしむら** 吃了手工荞麦面，set 套餐包括：

- 冷荞麦面（ざるそば）
- 天妇罗拼盘
- 豆腐味噌汤
- 渍物小碟

*￥1,980*，性价比很高。窗外就是桂川和渡月桥，景观位需要提前排队。
