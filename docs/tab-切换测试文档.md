# Oblet Tab 切换测试文档（批次 7.3）

> 版本：v0.1.0+tab (2026-08-03)
> 构建：`npm run tauri build` → `release/Oblet/oblet.exe`

## 测试环境

- Windows 10 / 11，WebView2 运行时已安装
- 准备 3 个测试用 .md 文件（A.md、B.md、C.md），内容可区分即可
- 测试前关闭所有已运行的 oblet.exe（`taskkill //F //IM oblet.exe`）

---

## 一、基础 Tab 切换

### 1.1 空窗口启动

- **操作**：双击 oblet.exe（不带参数）→ 显示起始页
- **预期**：无箭头、无异常

### 1.2 拖入第一个文件

- **操作**：拖入 A.md → 正常打开编辑
- **预期**：无箭头（仅 1 个 tab）

### 1.3 拖入第二个文件 → 箭头出现

- **操作**：拖入 B.md → 箭头在左右两侧出现
- **预期**：左/右两侧各有一个半透明箭头（opacity \~0.25），鼠标悬停时加深

### 1.4 点击箭头切换

- **操作**：点右箭头 → 切到 B.md → 点左箭头 → 切回 A.md
- **预期**：切换流畅（<100ms），标题栏文件名随切换更新

### 1.5 首尾循环

- **操作**：当前在 A.md（第一个 tab），点左箭头
- **预期**：切到最后一个 tab（循环），不卡死

---

## 二、键盘快捷键

### 2.1 Alt+Right / Alt+Left

- **操作**：Alt+Right → 下一个 tab；Alt+Left → 上一个 tab
- **预期**：与点击箭头行为一致，首尾循环

### 2.2 快捷键可改键

- **操作**：Ctrl+/ 开设置 → 快捷键列表找到「切换到下一个标签页」→ 点击 → 按新组合（如 Ctrl+Shift+Right）
- **预期**：新组合生效，双击恢复默认（Alt+ArrowRight）

---

## 三、Tab 内容缓存

### 3.1 编辑后切走再切回

- **操作**：在 A.md 中随意输入文字 → 切到 B.md → 切回 A.md
- **预期**：A.md 内容与切走前一致，光标回到上次位置附近

### 3.2 自动保存开时切 tab

- **操作**：确认设置中自动保存开启 → 编辑 A.md → 立即切到 B.md
- **预期**：A.md 自动保存到磁盘，切换无弹窗阻断

### 3.3 自动保存关时切 tab

- **操作**：Ctrl+/ → 编辑器 → 取消自动保存 → 编辑 A.md → 切到 B.md
- **预期**：弹出确认框「有未保存的更改，切换前要保存吗？」
  - 点「保存」：落盘后切换
  - 点「丢弃」：放弃修改后切换
  - 点「取消」或 Esc：留在当前 tab

---

## 四、Esc 关闭 Tab

### 4.1 多 tab 时 Esc 关当前

- **操作**：窗口有 A、B、C 三个 tab，当前在 B → 按 Esc
- **预期**：B 被关闭，自动切到 C（或 A，取决于 B 的位置）；若有脏内容且自动保存关则弹确认

### 4.2 单 tab 时 Esc 退起始页

- **操作**：窗口只剩一个 tab → 按 Esc
- **预期**：现有行为不变——弹确认（有脏内容时）→ 退回起始页

### 4.3 删到最后一个再 Esc

- **操作**：2 个 tab → Esc 关一个 → 只剩 1 个 → 再 Esc
- **预期**：弹确认 → 退回起始页

---

## 五、拖入行为

### 5.1 拖入新文件追加

- **操作**：已有 A.md，拖入 B.md
- **预期**：自动追加到 tab 列表末尾并切换到 B.md

### 5.2 拖入已在 tab 列表中的文件

- **操作**：已有 A、B、C → 从资源管理器再拖一次 B.md 进来
- **预期**：不重复添加，直接切换到已有的 B.md tab

### 5.3 拖入非 .md 文件

- **操作**：拖入 .txt 或 .png 文件
- **预期**：忽略，不添加 tab

---

## 六、新建笔记

### 6.1 起始页新建

- **操作**：起始页 → 点「新建 Markdown 笔记」→ 输入文件名 → 创建
- **预期**：打开编辑器（只有一个 tab），可正常编辑和保存

### 6.2 已有文件时新建的路径

- **操作**：暂不支持（无菜单入口，起始页只在空窗口显示）——**已知限制**

---

## 七、允许多窗口设置

### 7.1 默认关闭时双击 .md

- **操作**：设置中确认「允许多窗口」关闭 → Oblet 已有一个窗口 → 在资源管理器双击另一个 .md
- **预期**：新文件追加到当前窗口的 tab 列表，不另外打开新窗口

### 7.2 开启时双击 .md

- **操作**：Ctrl+/ → 界面 → 勾选「允许多窗口」→ 保存 → 双击另一个 .md
- **预期**：新文件在新窗口中打开（旧行为）

### 7.3 设置持久化

- **操作**：开启「允许多窗口」→ 关闭 Oblet → 重新打开 → 查看设置
- **预期**：设置保持开启状态

---

## 八、文件监听

### 8.1 当前 tab 被外部修改

- **操作**：Oblet 打开 A.md → 用记事本修改 A.md 并保存 → 切回 Oblet
- **预期**：无脏内容时自动重载；有脏内容时 toast 提示

### 8.2 非活跃 tab 被外部修改

- **操作**：Oblet 有 A、B 两个 tab，当前在 A → 用记事本修改 B.md 并保存 → 切到 B
- **预期**：显示 B 的最新内容（外部修改已被静默更新到缓存）

### 8.3 Tab 文件被外部删除

- **操作**：Oblet 有 A、B 两个 tab，当前在 A → 在资源管理器中删除 B.md → 切到 B
- **预期**：toast 提示文件已删除，B 从 tab 列表中移除，自动切回 A

---

## 九、异常与边界

### 9.1 快速连续切换

- **操作**：连续快速按 Alt+Right 5 次
- **预期**：不卡死、不崩溃，最终停在正确的 tab

### 9.2 窗口标题

- **操作**：在各种 tab 间切换
- **预期**：标题栏始终显示 `Oblet - {当前文件名}`

### 9.3 设置面板快捷键

- **操作**：设置面板打开时按 Alt+Left/Right
- **预期**：焦点在设置面板时不穿透切换 tab（现有快捷键输入守卫生效）

### 9.4 只读文件在 tab 列表中

- **操作**：将一个非 UTF-8 编码的文件拖入 tab 列表
- **预期**：切换到该文件时显示只读横幅，不可编辑

## 已知限制

1. **Undo 不跨 tab**：切 tab 后原 tab 的撤销历史丢失
2. **无标签栏**：只能通过箭头/快捷键切换，看不到 tab 列表
3. **无法从编辑态新建笔记**：新建入口仅在起始页
4. **Tab 列表不持久化**：关闭窗口后 tab 列表不保存，下次启动重新开始
