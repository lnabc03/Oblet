## 一、🔴 破坏 Obsidian 语义（必修）

### 1.1 wikilink / embed 被转义破坏

| 输入 | 现状输出 | 后果 |
|---|---|---|
| `[[链接]]`、`[[链接\|别名]]`、`参见 [[笔记A]]` | `\[\[链接]]` | Obsidian 双链失效（`\[` 渲染为字面 `[`） |
| `![[图片.png]]` | `!\[\[图片.png]]` | Obsidian 嵌入失效（`!` 因 safe() 相邻去重逻辑未被转义，只有 `[` 被转义） |

**根因**：`unsafe.js:122` `{character: '[', inConstruct: 'phrasing'}` 无条件转义文本中的 `[`。

**修复**（`keepObsidianSyntax` 后处理）：
- 撤销 `\[\[` → `[[`（成对起始括号）。
- **护栏**：匹配到 `]]` 后若紧跟 `(` 则不撤销——`[[a]](url)` 撤销后会被 CommonMark 解析成 字面`[` + 链接`[a](url)`，改变渲染。
- 已知边角（接受并记录）：文档中恰好存在 `[a]: url` 引用定义时，`[[a]]` 撤销后重解析会把 `[a]` 当 shortcut 引用链接。Obsidian 用户极少在含 wikilink 的文件里定义同名引用链接。

### 1.2 行首 `#标签` 被转义破坏

| 输入 | 现状输出 | 后果 |
|---|---|---|
| 行首 `#标签` | `\#标签` | Obsidian 行首标签失效；行中 `文字 #标签` 不受影响（非 atBreak 不转义） |

**根因**：`unsafe.js:69` `{atBreak: true, character: '#'}` 防 ATX 标题。

**修复**（`keepObsidianSyntax` 后处理）：
- 输出中的 `\#` 只可能出现在行首（phrasing 中无其它 `#` 转义规则），逐个判定：`#` 后字符**不是空白也不是 `#`** 时撤销转义（`#tag` 不可能构成 ATX 标题——标题要求 `#` 序列后跟空格或行尾）。
- `#` 后跟 `#`（如 `##tag`）保守保留转义。

### 1.3 footnote 现状（无需修，记录在案）

- `正文[^1]` + `[^1]: 定义` 同文件：**字节稳定** ✓——`[^1]` 走 reference link 路径解析（shortcut 引用 + definition），序列化原样写回。Obsidian 当 footnote 渲染，CommonMark 当引用链接，互不冲突。
- 边角：只有 `[^1]` 引用而**无定义**时，`[` 被转义为 `\[^1]`。无定义的 footnote 本就无效，接受。

## 二、🟡 渲染等价但源码污染（建议修前三项）

### 2.1 裸 URL / email 被改写（建议修）

| 输入 | 现状输出 |
|---|---|
| `https://example.com/page?q=1` | `<https://example.com/page?q=1>` |
| `www.example.com` | `[www.example.com](http://www.example.com)`（最难看） |
| `foo@bar.com` | `<foo@bar.com>` |

**根因**：GFM autolink literal 把裸 URL 解析成 link 节点；`gfmAutolinkLiteralToMarkdown()` 只追加了转义规则、**没有**把 link 节点还原为裸写的 transform；link handler 走 `formatLinkAsAutolink` 输出 `<url>` 形式。

**修复**（`tuneSerialization` handlers 覆盖 `link`）：
```ts
// 伪代码：识别"GFM literal autolink 形态"还原裸写，否则回落原 handler
const isLiteralAutolink = (node) =>
  node.title == null &&
  node.children?.length === 1 &&
  node.children[0].type === 'text' &&
  (node.children[0].value === node.url ||              // https://x.com
   'http://' + node.children[0].value === node.url ||  // www.x.com
   'mailto:' + node.children[0].value === node.url)    // foo@bar.com
```
- 命中时**直接返回 text 原文**（不过 safe()——URL 字符集无空格/括号失衡问题，重解析必还原为同一 literal autolink，往返稳定）。
- 未命中时调用 `prev.handlers.link` 回落默认逻辑。
- 注意 GFM literal autolink 允许平衡括号，裸写输出无需额外处理。

### 2.2 `&` 过度转义（建议修）

| 输入 | 现状输出 |
|---|---|
| `R&D` | `R\&D` |
| `C&#` | `C\&#` |

**根因**：`unsafe.js:73` `{character: '&', after: '[#A-Za-z]'}`——`&` 后见字母/`#` 就转义，不看是否真构成实体。

**修复**（后处理）：`\&` 后序列**确实构成实体引用**（`&(#[0-9]+|#[xX][0-9a-fA-F]+|[A-Za-z][A-Za-z0-9]+);`）时保留转义（否则重解析被解码），否则撤销。
- 自检用例：WYSIWYG 输入字面 `&amp;` → 文本节点含 `&amp;` → 必须保留 `\&amp;`（否则往返变 `&`）。

### 2.3 低优先级噪音（不修，记录）

- `a~b` → `a\~b`（GFM strikethrough 单 `~` 词内保守转义）
- `空括号 []` → `\[]`
- 单反引号 `` ` `` → `` \` ``（防配对成 code span，有必要）
- `**粗体_斜体_**` → 尾部 `\_`（闭 `**` 前的 `_` 被保守转义）

## 三、⚪ AST 结构归一化（无法无损修复，记入 CLAUDE.md "已知合理规范化"）

| 输入 | 输出 |
|---|---|
| `_斜体_` / `__粗体__` | `*斜体*` / `**粗体**`（强调标记统一） |
| `~~~lang` 围栏 | ` ``` ` 围栏 |
| `1) 列表` | `1. 列表` |
| setext 标题 `标题\n===` / `标题\n---` | ATX `# 标题` / `## 标题` |
| 表格 | 按列宽重新对齐、分隔行 `-` 数归一 |

| 连续多空行 | 折叠为一个空行 |
